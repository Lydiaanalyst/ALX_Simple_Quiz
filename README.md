# ALX_Simple_Quiz


# Simple Quiz Application

A basic interactive quiz built with **HTML and JavaScript**.  
The quiz asks a single question and provides instant feedback based on the user’s answer.

---

## Features
- Multiple-choice question using radio buttons.
- Feedback shown after submitting an answer.
- Validates if no option is selected before submission.

---

## How It Works
1. The user selects an answer from the given choices.  
2. When the **Submit Answer** button is clicked, the JavaScript function `checkAnswer` runs.  
3. If the selected answer is correct, feedback shows:  
   **"Correct! Well done."**  
4. If incorrect, feedback shows:  
   **"That's incorrect. Try again!"**  
5. If no option is selected, the user is prompted to choose an answer.
